# D5 Desktop の外部YAMLタブ

[Layout Issue #1](https://github.com/kubohiroya/turbowarp-plus-editor-layout/issues/1) の外部ファイル編集。作品分離を `TW_PLUS_DESKTOP_PROJECT_ISOLATION=1` で有効にし、`TW_PLUS_DESKTOP_EXTERNAL_YAML=1` で起動する。Plus 標準配置のファイルメニューから「外部YAMLファイルを開く…」を選ぶ。タブを別のパネルの端へドラッグすると分割表示できる。

- ファイル選択ダイアログが返した、4 MiBまでのUTF-8の `.yaml` または `.yml` ファイルを編集する。タブを開いたまま元ファイルに保存できる。外部ファイルと草稿はSB3のデータや配置復元に含めない。
- 同じ実ファイルを同じウィンドウで選び直すと既存のタブが開く。別作品のウィンドウでは同じファイルの編集を拒否する。シンボリックリンクは実体を照合し、ハードリンクは書き込み対象から外す。
- ファイルの外部変更や置換を保存前に検知した場合は、草稿を保持して書き込みを拒否する。保存は一時ファイルを同じフォルダーに作成してから置換する。閉じるとロックを解放し、プロセス異常終了時は起動係が回収する。排他の対象は同一ユーザー・同一ホストのローカルファイルシステム。
- 切り戻すには、編集中のファイルを保存または草稿を退避し、すべての作品ウィンドウと起動係を終了して、`TW_PLUS_DESKTOP_EXTERNAL_YAML=0` で起動する。

[macOSでの検証手順](project-json-transfer.md) で外部YAMLを含むEditorレンダラーを組み込み、`TW_D5_TEST_EXTERNAL_YAML=1` を追加する。ファイル選択結果だけを試験用のパスで置き換える。ファイルメニュー、Dockview、別作品プロセスのIPC、ロック、ファイル保存は実際の経路を通る。分割の操作はPlaywrightから行う。
