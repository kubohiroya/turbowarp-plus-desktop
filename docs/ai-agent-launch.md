# AI エージェントのアプリ起動

[Editor #478](https://github.com/kubohiroya/turbowarp-plus-editor/issues/478) の (b) の 4 と (c) のうち、Desktop でアプリを起動する部分（#38）。Plus renderer で `TW_PLUS_DESKTOP_AI_AGENTS=1` を指定して起動する。Mac App Store 版では使えない。

## 使い方

- TurboWarp Plus アイコンのメニュー「AI エージェント設定…」の「デスクトップアプリ」で、アプリを追加する。アプリは「選択…」から OS のファイル選択で選ぶ。macOS は `.app`、Windows は `.exe`、Linux は実行できるファイルに限る。`.bat`・`.cmd`・`.lnk`・`.desktop` などシェルや別の仕組みを通すものは受け付けない。
- 引数は 1 行に 1 つ。`{projectFolder}`・`{repository}`・`{branch}` を置き換える。値は同じ節の「プロジェクトフォルダを選択…」「Git リポジトリを選択…」で、OS のフォルダ選択から決める。プロジェクトフォルダが Git の作業ツリーの中にあれば、そのリポジトリも選ぶ。`{branch}` は `.git/HEAD` から読み、detached HEAD では値がない。
- 作業ディレクトリの既定は `{projectFolder}`。macOS の `.app` は `open -a` で起動するので、作業ディレクトリはアプリに渡らない。
- 保存すると、追加した項目と、アプリ・引数・作業ディレクトリを変えた項目を OS の確認ダイアログに並べる。「許可して保存」を選んだときだけ保存する。名前・並び順・代わりに開く Web サイトの変更は、確認を出さずに保存する。
- 左側ドロワーの AI エージェントのメニューで項目を選ぶと起動する。失敗したときは理由を出し、代わりの Web サイトがあればそれを開く項目を出す。

## 権限の境界

- 設定は main プロセスが Desktop のデータフォルダの `ai-agents.json` に保存する。作品分離のときも、すべての作品プロセスで同じファイルを使う。保存は改訂（内容の SHA-256）を確かめてから一時ファイルの rename で行う。
- レンダラーが渡せるのは、項目の ID・名前・引数・作業ディレクトリ・Web サイトの URL と、ファイル選択のたびに main が発行する使い捨ての札だけ。アプリのパスはレンダラーから受け取らない。札のない新しい項目や、知らない札は保存しない。
- 起動はシェルを通さず、引数を配列で渡す。`ELECTRON_*`・`TW_PLUS_*` などの環境変数は子プロセスに渡さない。
- ダイアログ・保存・起動は、ウィンドウごとに 1 つずつ実行する（重なると `busy`）。一覧と置き換えの値の読み取りは待たない。

## 切り戻し

`TW_PLUS_DESKTOP_AI_AGENTS` を外して再起動する。preload の `aiAgents` が `null` になり、Editor は Web 版と同じメニューに戻る。`ai-agents.json` は残る。
