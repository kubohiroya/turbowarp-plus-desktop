# D5 Desktop の素材転送領域

[Layout Issue #1](https://github.com/kubohiroya/turbowarp-plus-editor-layout/issues/1) の D5 のうち、コスチューム・音声のバイナリを作品プロセス間で受け渡す基盤。D3・D4 を有効にし、`TW_PLUS_DESKTOP_ASSET_TRANSFER=1` を設定した検証用の Desktop で利用できる。切り戻す場合は作品を保存し、Desktop の全プロセスを終了して `TW_PLUS_DESKTOP_ASSET_TRANSFER=0` で再起動する。

## 転送契約

- 作品ウィンドウのメインフレームから、種類とバイト列を起動係に渡す。起動係は1件につき最大32 MiBをユーザー専用の `project-transfers` に保存し、256 MiBまたは256件に制限する。ファイルは一時名で書いてから確定する。
- クリップボードやドラッグに載せる予定のJSONは `version`、`kind`、`transferId`、`payload`、`assets[]` を持つ。転送領域は `transferId` と、素材の論理ID・種類・サイズ・SHA-256だけを返す。受信側はパスを渡せない。作品間で転送するバイト列はバイナリIPCと専用領域を通る。
- 読み取りはサイズとSHA-256の一致を確認してからバイト列を返す。送信プロセスの終了後も15分の有効期間中は取得できる。転送を準備したプロセスは有効な参照を取り消せる。
- 起動係は期限切れと未確定ファイルを起動時・定期処理・新規の保存時に掃除する。期限切れ参照は掃除前でも使用できない。無効化中に残ったファイルは転送領域を再び有効にした起動係が掃除する。

## 検証

[DesktopのmacOS検証手順](project-json-transfer.md) に `TW_D5_TEST_ASSETS=1` を追加する。別作品プロセスでSVGとWAVを取得し、SHA-256が一致すること、既存VMで描画用のスキンと音声バッファが生成されることを確認する。送信プロセスの終了後に取得し、取消済みの参照とハッシュ不一致の参照では素材一覧が変わらないことも確認する。

`node --test test/project-assets.test.js` は期限切れ、改ざん、パス指定、再起動、転送領域の容量上限を検証する。

素材編集パネルからOSクリップボード・ドラッグの操作につなぐ作業と、外部YAMLのファイルタブは後続差分で扱う。
